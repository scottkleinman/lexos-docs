# README

This is the documentation site for the [Lexos Python library](https://github.com/scottkleinman/lexos).

The documentation content is maintained in this repo but deployed using git workflows to the Lexos repo's `gh-pages` branch. The live site is thus available at [https://scottkleinman.github.io/lexos/](https://scottkleinman.github.io/lexos/).

For older releases, add the version number, e.g. [https://scottkleinman.github.io/lexos/v0.1.0-beta.31/](https://scottkleinman.github.io/lexos/v0.1.0-beta.31/).
